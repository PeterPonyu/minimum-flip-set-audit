Small paired evaluations turn a handful of graded answers into a conclusion.
We analyze one completed evaluation of \Questions{} questions
under \ConditionsWord{} retrieval conditions, with \Answers{} graded answers
and \Contrasts{} recorded contrasts, and ask how few gradings
would have to change for each conclusion to stop holding.
One grading moves a question between the four paired counts, so the minimum
is exact.

For the image-dependent harm contrast, \HarmK{} grading is sufficient:
\HarmCandidates{} of its \HarmGradings{} gradings would each erase
the difference. Three nested string rules disagree on
\RegradeContested{} of \Answers{} answers; applying that rule
moves the difference from \HarmDiff{} to \RegradedDiff{}
points. The help contrast is \HelpDiff{} points the other way and
needs \HelpK{} gradings to reverse, but its non-significant verdict needs only
\HelpVerdictK{} (\(p=\HelpP{}\)). Under the stored rule \SurvivesHolm{} of
\Contrasts{} contrasts survive Holm correction, two of them the same
long-tail text table counted twice, so fewer distinct tables remain;
under the numeric-tolerant nested rule the long-tail text pair does not
(\(p=\NumericHolmLT{}\)). For
\Incapable{} contrasts the smallest attainable \(p\) already exceeds
\AlphaLevel{}.

The contribution is a minimum-change count on one annotation-limited
evaluation, and requires validation on a broader set of paired comparisons.
